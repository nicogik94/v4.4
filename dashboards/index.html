How to use this

The Decision Engine helps you think through hard decisions carefully. Here's the workflow:

  1. Create a project using the form below. Describe the decision in the brief.
  2. Classify the risk at create time. Default is "minimal risk". Change it if the decision is about employment, credit, insurance, or other Annex III categories.
  3. Run the project by clicking the row in the project list, then clicking "Run".
  4. Watch it work in the phase strip. It walks through 8 phases over a few minutes.
  5. Read the report when it finishes. Review every report before delivering it to a client.

If anything looks wrong, fire the kill switch. It stops the project immediately and persists the halt.
