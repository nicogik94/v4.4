# AI Automation ROI Prioritization

This is an example brief for demo use, not a first-class vertical template or
runtime pack.

## Decision Question

Which internal AI automation pilot should we prioritize for the next 60 days:
sales proposal drafting, support triage, finance reconciliation, or customer
success renewal preparation?

## Context

Several teams have proposed automation ideas. Leadership wants a focused pilot
that can show measurable ROI without introducing uncontrolled compliance,
quality, or operational risk.

## Constraints

- The pilot must use existing systems and data access.
- No customer-facing autonomous action is allowed.
- Legal review is required before external claims are automated.
- The pilot must produce measurable evidence within 60 days.
- Engineering capacity is limited to one part-time owner.

## Known Evidence

- Sales spends 6 to 8 hours per week on proposal drafts.
- Support triage volume is high but categories are inconsistent.
- Finance reconciliation has clear rules but sensitive data access.
- Renewal preparation has strong business value but fragmented source data.

## Unknowns

- Which workflow has the cleanest input data.
- Which workflow has the lowest review burden.
- Whether time savings can be measured without new tooling.
- Whether legal/compliance constraints change pilot scope.
- Which team has an accountable owner for weekly review.

## What A Good Recommendation Should Resolve

- Which pilot to prioritize first and why.
- Which pilots should be deferred.
- What evidence is needed before expanding automation.
- What human review gate is required.
- What monitoring signals define success, warning, and stop conditions.

## Suggested Files / Evidence To Upload If Available

- Process time estimates by workflow.
- Sample proposal, support, finance, or renewal artifacts.
- Data access inventory.
- Compliance or legal review notes.
- Team capacity estimates.
- Current quality/error metrics.

## Expected Output Types

- Decision report.
- Client dossier.
- Operator dossier.
- Client monitoring XLSX.
- Operator monitoring XLSX.
