# v4.4 Controlled Retrieval

This document describes the controlled-retrieval layer added after tranche 3A.

Scope implemented:

- backend-computed retrieval eligibility by phase
- whitelist-based prompt-exposure policy
- structured knowledge projection
- additive API visibility for eligible vs blocked knowledge

Not implemented:

- orchestration changes
- automatic reruns or invalidation
- raw prompt dumps
- unrestricted prompt-facing retrieval
- new connectors or background sync

## Core rule

`ProjectState` remains canonical and `knowledge_layer` remains additive.

Controlled retrieval is a **derived backend view** over synced knowledge items. It does not alter:

- workflow phase semantics
- `decision_objects`
- sync behavior

## Eligibility rules

Knowledge is eligible only when all of the following are true:

- source status is `current`
- item freshness is `fresh`
- source kind / connector type are allowed for the phase
- sensitivity is allowed by phase policy
- trust tier meets the phase minimum
- prompt-exposure policy leaves at least one whitelisted field after projection

Knowledge is blocked when it is:

- stale
- expired
- quarantined
- sensitivity-disallowed
- trust-below-threshold
- source-disabled / failed / not-current
- filtered out by prompt-exposure policy

## Structured projection

Projection is whitelist-based.

Allowed output today is bounded to:

- `title`
- `summary`
- selected scalar keys from `structured_payload`

Projection does **not** expose:

- raw payload dumps
- nested payload structures
- secrets
- prompt dumps or execution transcripts

## API visibility

Additive routes:

- `GET /projects/{id}/knowledge`
- `GET /projects/{id}/knowledge/retrieval`
- `GET /projects/{id}/knowledge/retrieval/{phase}`

`/knowledge` now includes a retrieval summary.

`/knowledge/retrieval/{phase}` returns:

- phase policy
- eligible items with structured projections
- blocked items with reasons

## Important boundary

Controlled retrieval is now computed and visible, but it is still **not wired into orchestration or prompt assembly automatically** in this version.
