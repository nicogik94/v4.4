# Wave 11.7 — Repo Hygiene for Generated Artifacts

## Goal

Remove tracked generated Python bytecode/cache artifacts from the Git index and ensure future bytecode generation does not dirty the repository.

## Scope

- Discover tracked generated artifacts with a read-only `git ls-files` filter.
- Classify candidates before changing the index.
- Untrack only safe generated Python bytecode/cache artifacts with `git rm --cached`.
- Keep sqlite/database artifacts, including `scenario_shadow.sqlite3`, tracked and untouched.
- Ensure `.gitignore` covers Python bytecode and pytest cache patterns.

## Non-Goals

- No source behavior changes.
- No test fixture removal.
- No sqlite/database artifact cleanup.
- No changes to eval semantics.
- No workflow, readiness, report/export, runtime, or app behavior changes.
- No cleanup-script rewrite unless behavior is clearly obsolete or unsafe.

## Files Changed

- `.gitignore`
- tracked Python bytecode files removed from the Git index only
- `ai_context/waves/wave_11_7_repo_hygiene_generated_artifacts.md`
- `ai_context/v4_v5_current_progress.md`

## Generated Artifacts Classified

- Tracked `__pycache__/*.pyc` files were classified as generated Python bytecode and removed from the Git index only.
- `scenario_shadow.sqlite3` was classified as a protected sqlite test artifact and left alone.
- No `.sqlite3`, `.db`, or fixture-like artifact was untracked, deleted, relocated, or rewritten.

## Cleanup Script

`scripts/wave_clean_artifacts.sh` was not changed. Its existing behavior remains useful for tracked artifacts such as `scenario_shadow.sqlite3`; after Python bytecode is de-tracked, it naturally has fewer tracked bytecode paths to restore.

## Verification Intent

Run a normal pytest command without `PYTHONDONTWRITEBYTECODE=1` to prove generated bytecode is ignored or absent and no longer dirties tracked files. Then run full wave verification.

## Human Review Boundary

This is repository hygiene only. MAS remains a local/operator-first decision-analysis engine. It is not a chatbot, BI surface, public SaaS, multi-tenant account system, or autonomous action system. Human review remains mandatory.
